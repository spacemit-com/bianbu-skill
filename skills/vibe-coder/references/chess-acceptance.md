# 中国象棋网页验收标准

## P0 功能

- 9×10 棋盘、楚河汉界、双方 32 枚棋子及标准初始布局。
- 红方先行，点击选择和点击目标位置走子；明确显示当前回合与选中状态。
- 车、马、相/象、仕/士、帅/将、炮、兵/卒的基础合法走法与阻挡规则。
- 将帅不得照面；不能执行使己方将帅处于被将军状态的走法。
- 吃子、将军提示、将死或无合法走法时结束对局。
- 人机对战：AI 至少能在所有合法走法中选择一步；推荐浅层 Minimax + Alpha-Beta，并设置时间/深度上限。
- 重新开始和悔棋；悔棋在人机模式下回退完整一轮。

## P1 体验

- 可切换先后手或难度。
- 最近一步高亮、可走位置提示、已吃棋子或步数展示。
- 窄屏可滚动或缩放，不能遮挡核心控制按钮。

## 稳定选择器

建议提供：`#chess-board`、`#game-status`、`#restart-button`、`#undo-button`、`#difficulty-select`。棋盘交点应带 `data-row`、`data-col`，棋子应带 `data-piece`。

## 验证限制

静态验证只能证明结构、危险模式和资源引用满足要求。完整规则正确性需使用确定性局面测试或人工对局验证；未执行时必须标注为未验证。
