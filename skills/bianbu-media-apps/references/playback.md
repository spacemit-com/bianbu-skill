# 日常播放与控制

普通使用不读取用例表，不调用验收脚本。

适用于 mpv、Totem、VLC；先按 applications.md 选择用户指定应用。以下默认启动规则按目标程序分别使用 `mpv 视频路径`、`totem 视频路径`、`vlc 视频路径`，不加硬解、输出或调试参数，不在播放器之间擅自替换。Snapshot 使用 snapshot.md。

## 打开与播放

1. 从当前请求获取实际媒体路径/URL，或明确的文件选择。不能用历史测试素材替代用户视频；不为普通播放自动生成样片。
2. 在板端当前真实图形会话操作。只有 SSH 时，从实际会话确定 DISPLAY / WAYLAND_DISPLAY / XDG_RUNTIME_DIR；不臆造显示编号。没有可用桌面则说明无法打开可见窗口，不能以后台解码冒充播放。
3. 使用目标应用现有入口、文件管理器或正常启动命令。**默认只传程序名和媒体路径。** 路径含空格/中文时由进程工具传参保证完整，例如 `["vlc", "/home/bianbu/Videos/实际视频.mp4"]`。mpv 保持 `mpv 视频路径` 无额外参数。不把未转义路径拼成 shell 代码；以连字符开头的相对文件名先解析为绝对路径。
4. 用户只说打开应用时，使用该应用平台入口；纯命令场景按平台方式执行程序名。mpv 无文件时若退出，优先使用已安装桌面入口，不擅自补 `--idle` / `--force-window`。Totem 等单实例应用可能将请求交给已有窗口后启动进程退出，需查目标窗口，不能单以新 PID 退出判失败。
5. 用执行工具支持的非阻塞/后台方式保留图形播放进程，记录本次 PID 和直接启动错误。后台执行是进程管理方式，不是在 mpv 命令上追加参数。不得通过会自动退出的测试包装器播放用户视频。
6. 短暂确认窗口/媒体进入播放状态，然后结束当前操作并保留播放器。不等待影片结束、不自动关闭；无需验收报告或重复解码测试。

## 暂停、继续、音量、Seek、全屏、关闭

- 定位当前目标实例，使用其真实 GUI 控件/键盘。已有受控 IPC/应用控制接口时也可用于日常操作，但不重启应用以添加控制参数。mpv JSON IPC 不适用于 Totem/VLC；不能向其他程序发送 mpv 命令。
- 按当前实际绑定操作，尤其不要把 ↑↓ 想当然当成音量键；使用核对过的增/减音量键或适用控件。
- 暂停/继续和全屏/退出全屏优先设置目标状态，避免未知状态下盲目 toggle。按用户给定音量值或增减量执行，不准备测试音、不测音画同步。
- 用户要求关闭时，仅正常关闭目标播放器；未要求关闭则保留。普通操作允许等效手段，验收中的指定步骤限制不套用到日常请求。

## 最小验证

检查一次目标窗口/播放状态或直接启动结果。有画面推进证据时说“已用 VLC/Totem/mpv 播放……”，使用实际程序名。只能确认启动时说“已启动……并载入……”，不编造声音、同步或硬解验证结果。

首次失败可核对文件存在性、实际桌面会话和直接错误，最多做一次有依据的重试。不要为日常播放改 vo/ao/hwdec、绕过默认配置、更新播放器、重启桌面或改驱动。
